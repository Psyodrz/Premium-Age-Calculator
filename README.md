# Premium Age Calculator

A beautifully designed, highly precise age calculator built completely from scratch using vanilla web technologies. It goes beyond simple years and months, providing an exact breakdown of the total days, weeks, hours, and minutes you've been alive, along with fun extras like your Zodiac sign.


## 🌟 Features

*   **Human-Crafted Aesthetic:** A highly refined, editorial design built without relying on standard UI libraries. Features custom gradient orbs, subtle dot-grid backgrounds, and smooth CSS animations.
*   **Precision Math Engine:** Accurately calculates age across leap years and months with differing day counts.
*   **Total Lifetime Stats:** See exactly how many total days, weeks, hours, and minutes you've lived.
*   **Robust Validation:** Complete edge-case handling (e.g., February 30th, future dates, invalid month combinations).
*   **Fully Responsive:** A dynamic two-column grid layout that beautifully fills large widescreen monitors while collapsing gracefully for mobile devices.

## 🛠️ Built With

*   **Vanilla HTML5:** Semantic, accessible structure.
*   **Vanilla CSS3:** Custom design tokens, complex masking, CSS grid, and `requestAnimationFrame` style keyframes.
*   **Vanilla JavaScript (ES6+):** Complete DOM manipulation, form validation, and complex `Date()` object math—zero dependencies.

## 🚀 Getting Started

1.  Clone this repository:
    ```bash
    git clone https://github.com/Psyodrz/Premium-Age-Calculator.git
    ```
2.  Navigate to the directory:
    ```bash
    cd Premium-Age-Calculator
    ```
3.  Open `index.html` in your favorite web browser.
